answers.

Simple information to help you get familiar with Loop Proxy.

What can I do with Loop Proxy?

Control your VPN connection, browse available server entries, run a speed test, review usage and recent sessions, and use the built-in browser and bookmarks.

What does the speed test show?

The speed-test screen displays download speed, upload speed and ping. Results depend on current network conditions and are not a guarantee of future performance.

Which server routes are available?

Check the server list inside the app for currently available entries and displayed latency. Route availability can change; this page does not promise a particular country or server count.

Where can I read the privacy policy?

Read our Privacy policy for information about data handling and how to contact us about privacy.
